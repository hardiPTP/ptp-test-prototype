# Push The Pin test prototype

A user testing prototype of Push The Pin for Bandra West, Mumbai. Open it on a phone:

https://hardiptp.github.io/ptp-test-prototype/

It is one self-contained `index.html`. Posts, deals and offers in it are samples. Everything a tester does is kept in their own browser; "Reset this test" in the account screen clears it between testers.
